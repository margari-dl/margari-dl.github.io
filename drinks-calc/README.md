# Калькулятор корректировки купажа и сиропа

Калькулятор для корректировки алкогольных и безалкогольных напитков. Считает, сколько добавить спирта, сахарного сиропа, воды и лимонной кислоты Е330, чтобы крепость, экстракт (сухие вещества) и кислотность попали в диапазон стандарта.

## Как пользоваться
Откройте ссылку на сайт калькулятора, выберите тип напитка, введите фактические значения (для безалкогольных — ещё и стандарт).

## Установка как приложение (работает без интернета)
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран Домой».
- **Компьютер (Chrome / Edge):** значок установки в адресной строке.

После первого открытия калькулятор работает без сети. Обновления подтягиваются сами, когда устройство в сети.

## Обновление
Замените `index.html`. В `sw.js` увеличьте номер версии (`drinks-calc-v1` → `drinks-calc-v2`), чтобы установленные приложения получили новую версию.
